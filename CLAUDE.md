# Whisper Voice Challenge

Read [AGENTS.md](AGENTS.md) and follow its installation contract.
Read [docs/AGENT-INSTALLATION.md](docs/AGENT-INSTALLATION.md) for the agent procedure
and [docs/INSTALLATION.md](docs/INSTALLATION.md) for shared operations.

Agents normally use `./deploy.sh` on `main`; humans can also use the
documented direct Helm procedure in `docs/HELM-INSTALLATION.md`.
The first challenge language is a required owner choice. The RHDP demo Llama
must be explicitly released with `--free-rhdp-gpu` when authorized.
Do not depend on prior chat memory or local ignored files for installation.
